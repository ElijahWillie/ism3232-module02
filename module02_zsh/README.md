# ISM3232 - Module 2: zsh Navigation and File Operations 


## Commands Practiced


| Command      | What it does                              |
|--------------|-------------------------------------------|
| pwd          | Prints the current working directory      |
| ls           | Lists visible files and folders           |
| ls -la       | Lists all files including hidden ones     |
| cd           | Changes directories                       |
| mkdir        | Creates a directory                       |
| rm           | Removes files and directories             |
| touch        | Creates a file                            |
| code         | Opens files or directories                |
| cp           | Copies files, etc.                        |
| mv           | Moves and renames files                   |
| cat          | Prints the content of a file in terminal  |
| head         | displays the beginning of a file          |
| echo         | prints texts or values to terminal        |
| tree         | visualizes structure of files/directories |
| python3      | runs the python3 interpreter in terminal  |
| .venv        | Python virtual environment folder         |
| pip          | Python's package installer                |
| alias        | creates shortcut for another term. command|
| deactivate   | exits python virtual environment          |
| source       | runs shell script in current shell session|
